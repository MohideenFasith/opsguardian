# Optional Higgsfield submission-media plan

Higgsfield is optional presentation support only. It is **not** a dependency of OpsGuardian and generated footage must never be presented as evidence that Strands, Bedrock, or AgentCore actually ran.

## Devpost cover image

Create a clean 16:9 hero image showing an operations console with a single incident timeline moving from alert → investigation → validation → human approval → resolved. Avoid AWS logos unless their use is permitted; use generic cloud/agent visual language. Text should be limited to “OpsGuardian” and “Autonomous incident response”.

## Four-second video bumper

A restrained data-pipeline graph lights up, one node turns warning amber, an agent trace moves through investigation and validation, then pauses at a human approval gate. End on “OpsGuardian”. No fake terminal output or cloud-console screenshots.

## Social image

Square composition: a human engineer focused on one approval decision while automated incident steps complete in the background. Emphasize the idea “Automate toil. Preserve judgment.”

## Demo rule

The actual demo section must be a real screen recording of the web application and, if claimed, a real AgentCore deployment/invocation. Generated media belongs only in the intro/outro.
